# Unit 2: React JS — Lab Sheet Q8–Q13

Each question has its own independent Vite + React project folder.

For every question, open that question's folder in VS Code and run:
```bash
npm install
npm run dev
```

Use the local URL printed in the terminal. Take your own screenshots of the running output for submission. For Q13, also run `npm run build` and `npm run preview`.

**Personalize Q8:** edit `src/App.jsx` and replace `Your College Name` with your college's actual name.
